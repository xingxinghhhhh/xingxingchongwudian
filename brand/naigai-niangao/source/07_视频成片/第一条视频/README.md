# 第 1 条视频：它们是谁

这是 `奶盖和年糕的 AI 成长日记` 的正式开场视频。

目标不是讲复杂剧情，而是让用户在第一眼就记住两件事：

1. 奶盖是一只高冷、慢热、嘴硬的小猫。
2. 年糕是一只热情、黏人、想和全世界做朋友的小狗。

同时给账号立下一个稳定预期：

> 从今天开始，记录它们一起长大的日子。

---

## 今日使用素材

按最终成片顺序使用这 4 张：

1. `奶盖标准图.png`
   - 用途：介绍奶盖
   - 画面建议：轻微推进，突出眼神和高冷感

2. `年糕标准图.png`
   - 用途：介绍年糕
   - 画面建议：轻微推进或轻微上移，突出笑脸和耳朵

3. `同框标准图.png`
   - 用途：建立双主角关系
   - 画面建议：轻微放大，停留在奶盖淡定、年糕热情的反差上

4. `睡觉陪伴图.png`
   - 用途：结尾营造陪伴感
   - 画面建议：缓慢放大，做温柔收尾

---

## 推荐时长

- 总时长：`18 秒`
- 适用平台：抖音 / 小红书
- 形式：图片视频

## 剪映制作步骤

1. 新建 `9:16` 竖屏项目
2. 导入以上 4 张图
3. 按 `4 / 4 / 5 / 5` 秒设置时长
4. 每张图只加一种轻动效：
   - 轻微推进
   - 缓慢放大
   - 很轻的左右平移
5. 字幕统一放在下三分之一位置
6. 字体建议：
   - 苹方 / 思源黑体
   - 白字
   - 轻阴影或半透明描边
7. 背景音乐选温柔治愈系，不要用搞怪音效
8. 导出：
   - `1080p`
   - `25fps` 或 `30fps`

## 旁白版文案

如果只上字幕，可以直接用上面的字幕内容。

如果要加旁白，建议用这版：

```text
这是奶盖。
一只看起来不太好接近的小猫。

这是年糕。
一只想和全世界做朋友的小狗。

一个假装不在意，
一个每天都想贴贴。

从今天开始，
记录它们一起长大的日子。
```

配音建议：

- 温柔女生声
- 治愈男声
- 轻声旁白

不建议使用夸张卖萌音。
