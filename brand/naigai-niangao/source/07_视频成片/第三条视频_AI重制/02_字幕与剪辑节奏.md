# 字幕与剪辑节奏

总时长：15-18 秒

音乐：温柔、轻快、治愈，不要强节奏，不要搞笑音效。

## 成片结构

### 0-5 秒

画面：奶盖在高处偷偷观察

字幕：

```text
奶盖总说，
自己不关心年糕。
```

### 5-10 秒

画面：年糕玩球，突然抬头发现奶盖

字幕：

```text
但只要年糕一动，
它就会偷偷看过去。
```

### 10-15 秒

画面：年糕发现奶盖，奶盖立刻装作没看见

字幕：

```text
年糕一抬头，
它又装作没看见。
```

### 15-18 秒

画面：如果第三段够长，就继续用第三段；如果不够，用备用温馨补镜

字幕：

```text
嘴硬的小猫，
真的很会演。
```

## 字幕风格

位置：画面下方 20%-25%，不要挡住猫狗脸。

字体：白色圆体或黑体，轻微黑色描边。

节奏：每句停留 2 秒左右，不要太快。
