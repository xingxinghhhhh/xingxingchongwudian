# Naigai & Niangao Brand Library

This folder is the migrated content library from `D:\AI\奶盖和年糕的成长日记`.

It keeps the brand project that the website is built around in one repo, so the site, character settings, scripts, and image assets can evolve together.

## Structure

- `source/`
  - A preserved copy of the original project folders and filenames.
- `character-profile.md`
  - UTF-8 character/world-setting reference for Naigai and Niangao.
- `prompt-master.txt`
  - Reusable visual prompt base for generating consistent character scenes.
- `first-five-video-scripts.txt`
  - Early short-video script drafts for Douyin / Xiaohongshu content.
